Données collectées via le formulaire de contact

Lorsque vous remplissez notre formulaire de demande de devis, nous collectons les informations suivantes :

  • Prénom et nom
  • Adresse email
  • Numéro de téléphone (facultatif)
  • Nom de votre entreprise ou structure
  • Secteur d'activité et effectif
  • Message libre (facultatif)

Finalité : ces données sont utilisées uniquement pour vous recontacter dans le cadre de votre demande de mise à disposition d'un distributeur automatique.

Base légale : intérêt légitime (réponse à une demande commerciale entrante).

Conservation : vos données sont conservées 3 ans maximum à compter de votre demande, puis supprimées.

Sous-traitant formulaire : les données transitent par Formspree (États-Unis), conforme RGPD via clauses contractuelles types.

Mesure d'audience — Google Tag Manager & Google Analytics

Ce site utilise Google Tag Manager (GTM-T8VV9Q6L) pour gérer les outils de mesure d'audience.

Google Analytics peut collecter des données anonymisées sur la navigation (pages visitées, durée, source de trafic). Ces données sont utilisées uniquement pour améliorer le site et comprendre l'audience. Aucune donnée n'est vendue ou partagée à des fins publicitaires.

Vous pouvez refuser la collecte via l'extension Google Analytics Opt-out.

Vos droits

Conformément au RGPD, vous disposez des droits suivants sur vos données personnelles :

  • Droit d'accès — savoir quelles données nous détenons sur vous
  • Droit de rectification — corriger des données inexactes
  • Droit à l'effacement — demander la suppression de vos données
  • Droit à la portabilité — recevoir vos données dans un format lisible
  • Droit d'opposition — vous opposer à tout traitement

Pour exercer ces droits, contactez-nous à contact@ymsmooth.fr. Nous vous répondrons dans un délai d'un mois.

Vous disposez également du droit de déposer une réclamation auprès de la CNIL.

Cookies

Google Tag Manager et Google Analytics peuvent déposer des cookies de mesure d'audience sur votre navigateur. Ces cookies sont strictement limités à la mesure d'audience et n'ont aucune finalité publicitaire. Vous pouvez les refuser via les paramètres de votre navigateur ou via l'extension Google Analytics Opt-out.

Sécurité

Le site est hébergé sur GitHub Pages (HTTPS). Les données de formulaire transitent via Formspree en HTTPS. Nous ne stockons pas vos données sur nos propres serveurs.
